# NJIK Careers

نموذج التقديم للوظائف في موقع نجيك.

## العمل

- الفرع الرئيسي: `main`
- أي تحديث يصل إلى `main` يسحبه السيرفر وينشره تلقائيا خلال 30 ثانية.
- بيانات قاعدة البيانات والبريد محفوظة في `config.local.php` على السيرفر ولا ترفع إلى GitHub.
- ملفات السير الذاتية والسجلات لا تدخل المستودع ولا تستبدل أثناء النشر.

## فحص محلي

1. انسخي `config.example.php` إلى `config.local.php` وضعي إعدادات بيئة التطوير.
2. شغلي `php -S 127.0.0.1:8080`.
3. افتحي `http://127.0.0.1:8080/careers.php`.

لا تضعي بيانات الإنتاج أو السير الذاتية في GitHub.
